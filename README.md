# 📊 Sales & Customer Performance Dashboard

An end-to-end Data Analytics & Business Intelligence solution analyzing product performance, customer metrics, and revenue trends using PostgreSQL and Power BI.

![Dashboard Screenshot](images/dashboard_overview.png)

## 🛠️ Tech Stack & Architecture

- **Database:** PostgreSQL hosted on [Aiven Console](https://console.aiven.io/account/a5d58f2ddd29/project/guptaujjwal379-cc5c/services/sales-db-project/overview)
- **ETL Pipeline:** Python script (`etl_pipeline.py`)
- **Data Modeling & Transformation:** Power Query / M
- **Analytics & Visualizations:** Power BI Desktop

---

## 💡 Key Highlights & Business Insights

- **Top Product Performance:** Analyzed revenue drivers across luxury watch models (e.g., *Rolex Datejust* generated **$35,907.26** in overall profit).
- **Customer Segmentation:** Derived customer purchasing frequency to identify high-value buyer cohorts.
- **Data Engineering:** Query views built on PostgreSQL (`vw_customer_summary`, `vw_product_performance`) for optimal data reporting.
